## 実データ確認時の安全ルール

- まず本番で使わない対象日を選びます。
- CSV取込は最初に1件だけで確認します。
- 取込前にプレビューの判定、登録件数、スキップ件数を確認します。
- ダイヤテンプレート作成は、既存便番号と重ならない日付で実行します。
- 確認後、不要なテストデータは画面上の削除操作で`deleted: true`にします。
- Firestore Consoleで直接データを消す場合は、操作履歴との整合性に注意します。
