# Phase 2開発計画

Phase 2では、Phase 1で作った日次運用の土台に対して、見える化、入出力、分析を段階的に追加します。

## 優先順位

| 優先 | 機能 | 目的 | 状態 |
| --- | --- | --- | --- |
| 1 | ダッシュボード | 当日の便・タスク進捗をすぐ把握する | 実装済み |
| 2 | Excel/CSV出力 | 当日計画・実績を外部共有しやすくする | 未着手 |
| 3 | Excel/CSV取込 | 便・タスク計画をまとめて登録する | 未着手 |
| 4 | 実績分析 | 作業時間、完了率、遅れを振り返る | 未着手 |
| 5 | ダイヤテンプレート | 定型便・定型タスクを再利用する | 未着手 |
| 6 | 入力改善 | フォーム操作、入力チェック、エラー表示を改善する | 未着手 |
| 7 | Rules自動テスト | 権限事故を自動検知する | 未着手 |

## Phase 2-1 ダッシュボード

管理者向けに、対象日の状況を集計する画面を追加しました。

- 便数、タスク数、前工程待ち、実績開始件数
- 作業員別タスク進捗
- ステーション別便進捗
- 作業中タスク
- 次の未完了タスク

Firestoreの既存データを購読して集計するだけなので、Cloud Functionsは使いません。

## 次に着手する候補

次は、運用で使いやすい **CSV/Excel出力** から進めるのがおすすめです。

まずはブラウザ内でCSVを生成し、以下を出力対象にします。

- 当日の便一覧
- 当日のタスク一覧
- 実績時刻
- 操作履歴

Excel取込はデータ破壊リスクがあるため、出力で項目設計を固めてから進めます。
