# Phase 2受入確認

## 判定

Phase 2は、主要機能の実装としては受入確認へ進める状態です。
次の確認シナリオを通し、`lint`、`build`、`test:rules` が成功すれば、Phase 2完了として扱えます。

## 実装範囲

| 区分 | 内容 | 状態 |
| --- | --- | --- |
| ダッシュボード | 当日の便・タスク進捗、作業員別/ステーション別進捗、未完了タスク確認 | 実装済み |
| CSV出力 | 便、タスク、操作履歴、実績時刻のCSV出力 | 実装済み |
| CSV取込 | 便・タスクCSVの事前判定、新規登録、既存スキップ、判定CSV出力 | 実装済み |
| 実績分析 | 完了率、平均時間、開始遅れ、作業員別/ステーション別実績 | 実装済み |
| ダイヤテンプレート | 定型便・定型タスクの一括作成、重複・時間かぶり確認 | 実装済み |
| 入力改善 | 主要フォームの保存前チェック、警告、保存ボタン制御 | 実装済み |
| Rules自動テスト | 代表的な管理者・一般ユーザー権限テスト | 実装済み |

## 受入確認シナリオ

### 1. ダッシュボード

1. 管理者でログインする。
2. 対象日を選択する。
3. 便数、タスク数、前工程待ち、実績開始済み件数が表示される。
4. 作業員別タスク進捗が表示される。
5. ステーション別便進捗が表示される。
6. 作業中タスクと次の未完了タスクが表示される。

### 2. CSV出力

1. `CSV出力` 画面を開く。
2. 便一覧CSVを出力できる。
3. タスク一覧CSVを出力できる。
4. 操作履歴CSVを出力できる。
5. Excelで開いたときに文字化けしない。

### 3. CSV取込

1. `CSV取込` 画面を開く。
2. 取込対象を `便` にして `テンプレート出力` から便テンプレートCSVを出力できる。
3. 取込対象を `タスク` にして `テンプレート出力` からタスクテンプレートCSVを出力できる。
4. CSVを読み込むと、プレビューに `登録予定`、`スキップ`、`要修正` が表示される。
5. 必須項目不足、マスタ不一致、時刻不正、重複、時間かぶりが検出される。
6. エラー行CSV、スキップ行CSV、判定CSVを出力できる。
7. `既存はスキップ` モードで既存行を除外し、新規行だけ登録できる。
8. 登録後に便・タスクが作成され、operationLogsに記録される。
9. 既存便・既存タスクは上書きされない。

### 4. 実績分析

1. `実績分析` 画面を開く。
2. タスク完了率、便完了率、平均タスク時間、開始遅れ件数が表示される。
3. 作業員別タスク実績が表示される。
4. ステーション別便実績が表示される。
5. 実績開始・完了が記録されていないデータがあっても画面が壊れない。

### 5. ダイヤテンプレート

1. `テンプレート` 画面を開く。
2. テンプレートを選ぶと作成予定の便・タスクが表示される。
3. マスタ不足、便番号重複、時間かぶりがある場合は作成前に警告される。
4. 問題がなければ `テンプレート作成` から便・タスクを一括作成できる。
5. 作成結果に便・タスクの詳細が表示される。
6. 作成時にoperationLogsが記録される。

### 6. 入力改善

1. 便管理、タスク管理、マスタ管理、ユーザー管理、便紐付け画面を開く。
2. 必須入力が不足している場合、保存前チェックに理由が表示される。
3. 致命的な入力不足がある場合、保存ボタンが無効化される。
4. 重複や時間かぶりは警告として表示される。
5. 警告だけの場合は、確認後に保存できる。

### 7. Firestore Rules自動テスト

1. Javaがインストールされていることを確認する。

```powershell
java -version
```

2. Rulesテストを実行する。

```powershell
npm.cmd run test:rules
```

3. 次の結果になることを確認する。

```text
7 Firestore rules tests passed
```

途中に `PERMISSION_DENIED` が出る場合がありますが、拒否されるべき操作を確認しているログであれば正常です。

## 仕上げ確認コマンド

```powershell
npm.cmd run lint
npm.cmd run build
npm.cmd run test:rules
```

## 残す判断

次の項目はPhase 2完了条件には含めません。必要になった時点で別フェーズまたは追加改善として扱います。

- 既存データを上書きするCSV取込モード
- 本格的なExcel `.xlsx` 出力
- Cloud Functionsによるサーバー側集計
- 大規模データ向けのページング・仮想スクロール
- CI環境でのRules自動テスト実行
